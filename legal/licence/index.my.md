## အကြောင်းအရာ: Creative Commons Zero 1.0 Universal (CC0 1.0)

စွယ်စုံကျမ်းအကြောင်းအရာအားလုံးကို [Creative Commons Zero 1.0 Universal (CC0 1.0)](https://creativecommons.org/publicdomain/zero/1.0/) အောက်တွင် အများပိုင်အဖြစ် ထုတ်ဝေထားပါသည်။

ဤတွင် အကျုံးဝင်သည်:

- ဘာသာစကားအားလုံးဖြင့် စုစည်းထားသော ဆောင်းပါးများ
- အဆိုပြုချက်များနှင့် ၎င်းတို့၏ ကိုးကားချက်များ
- အထောက်အထားအမှတ်များနှင့် အယ်လဂိုရီသမ်အကဲဖြတ်ချက်များ
- ဒေါင်းလုဒ်ရယူနိုင်သော SQLite အသိပညာဂရပ်
- စုစည်းရေး pipeline ဖြင့် ထုတ်လုပ်ထားသော ဘာသာပြန်ချက်များ

မည်သူမဆို ခွင့်ပြုချက်မတောင်းဘဲ သို့မဟုတ် အမည်ဖော်ပြခြင်းမလိုဘဲ မည်သည့်ရည်ရွယ်ချက်အတွက်မဆို ဤအကြောင်းအရာကို အသုံးပြု၊ ကူးယူ၊ ပြင်ဆင်နှင့် ပြန်လည်ဖြန့်ဝေနိုင်ပါသည်။

## ကုဒ်: MIT လိုင်စင်

Anomalica repository များရှိ ရင်းမြစ်ကုဒ်အားလုံးကို [MIT လိုင်စင်](https://opensource.org/licenses/MIT) အောက်တွင် ထုတ်ဝေထားပါသည်။ ဤတွင် အကျုံးဝင်သည်:

- static ဝက်ဘ်ဆိုက် (anomalica-site)
- အဝင်၊ အချေ နှင့် စုစည်းရေး pipeline များ
- ပံ့ပိုးကိရိယာများနှင့် script များ

## ရင်းမြစ် အထောက်အထားများ

အဆိုပြုချက်များ ထုတ်ယူထားသော မူရင်းစာရွက်စာတမ်းများသည် ၎င်းတို့၏ ကိုယ်ပိုင်မူပိုင်ခွင့်အခြေအနေကို ထိန်းသိမ်းထားပါသည်။ အစိုးရအစီရင်ခံစာများ၊ ကြားနာမှုမှတ်တမ်းများ၊ သတင်းဆောင်းပါးများ၊ စာအုပ်များနှင့် အခြားထုတ်ဝေထားသော အထောက်အထားများသည် ၎င်းတို့၏ သက်ဆိုင်ရာ တရားစီရင်ပိုင်ခွင့်နယ်ပယ် ဥပဒေများအရ ဖြစ်ပါသည်။

Anomalica ၏ open လိုင်စင်များသည် ထုတ်ယူပြီး စုစည်းထားသော ရလဒ်အတွက် သက်ဆိုင်ပြီး ရင်းမြစ်အထောက်အထား ကိုယ်တိုင်အတွက် မသက်ဆိုင်ပါ။ အသိပညာဂရပ်တွင် ဇာစ်မြစ်မက်တာဒေတာပါ ဖွဲ့စည်းထားသော အဆိုပြုချက်များ ပါဝင်သော်လည်း ရင်းမြစ်စာရွက်စာတမ်းများကို အပြည့်အစုံ ပြန်လည်ထုတ်လုပ်ထားခြင်း မဟုတ်ပါ။

## တတိယပုဂ္ဂိုလ် အစိတ်အပိုင်းများ

ဤဝက်ဘ်ဆိုက်သည် သက်ဆိုင်ရာ လိုင်စင်များအောက်တွင် open-source ဆော့ဖ်ဝဲ အစိတ်အပိုင်းများကို အသုံးပြုပါသည်:

- Hugo (Apache 2.0)
- Tailwind CSS (MIT)
- Alpine.js (MIT)
- GoatCounter (ဥရောပသမဂ္ဂ အများပြည်သူ လိုင်စင်)
- Noto Sans ဖောင့် (SIL Open Font Licence)
- Outfit ဖောင့် (SIL Open Font Licence)
