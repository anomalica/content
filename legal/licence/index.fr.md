## Contenu : Creative Commons Zero 1.0 Universal (CC0 1.0)

Tout le contenu encyclopédique est versé dans le domaine public sous [Creative Commons Zero 1.0 Universal (CC0 1.0)](https://creativecommons.org/publicdomain/zero/1.0/).

Cela couvre :

- Les articles assemblés dans toutes les langues
- Les affirmations et leurs attributions
- Les scores de preuve et les évaluations algorithmiques
- Le graphe de connaissances SQLite téléchargeable
- Les traductions produites par le pipeline d'assemblage

Toute personne peut utiliser, copier, modifier et redistribuer ce contenu à toute fin sans demander d'autorisation ni fournir d'attribution.

## Code : Licence MIT (MIT Licence)

Tout le code source des dépôts Anomalica est publié sous la [Licence MIT (MIT Licence)](https://opensource.org/licenses/MIT). Cela couvre :

- Le site statique (anomalica-site)
- Les pipelines d'ingestion, de digestion et d'assemblage
- Les outils et scripts de support

## Matériel source

Les documents originaux dont les affirmations sont extraites conservent leur propre statut de droit d'auteur. Les rapports gouvernementaux, transcriptions d'auditions, articles de presse, livres et autres publications sont soumis aux lois de leurs juridictions respectives.

Les licences ouvertes d'Anomalica s'appliquent aux résultats extraits et assemblés, et non au matériel source lui-même. Le graphe de connaissances contient des affirmations structurées avec des métadonnées de provenance, mais ne reproduit pas les documents sources dans leur intégralité.
