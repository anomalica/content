Anomalica dirancang untuk menghormati privasi pengunjung. Halaman ini menjelaskan data apa yang dikumpulkan, bagaimana data tersebut digunakan, dan hak apa yang dimiliki pengunjung.

## Analitik

Anomalica menggunakan GoatCounter, alat analitik web sumber terbuka yang menghormati privasi. GoatCounter tidak menggunakan cookie, tidak mengumpulkan data pribadi, dan tidak melakukan sidik jari perangkat.

Data agregat berikut dikumpulkan:

- Halaman yang dikunjungi
- Situs web perujuk (dari mana Anda berasal)
- Lokasi tingkat negara (diperoleh dari alamat IP, yang tidak disimpan)
- Jenis peramban dan ukuran layar

Data ini digunakan untuk memahami bagaimana situs digunakan dan untuk memprioritaskan konten. Data ini tidak dapat digunakan untuk mengidentifikasi pengunjung individu.

GoatCounter dihosting sendiri pada infrastruktur Uni Eropa. Tidak ada data analitik yang dibagikan kepada pihak ketiga.

## Cookie

Anomalica tidak menetapkan cookie. Preferensi mode gelap dan satuan pengunjung disimpan di penyimpanan lokal peramban. Data ini tidak pernah meninggalkan perangkat pengunjung dan tidak dapat diakses oleh Anomalica.

## Persetujuan

Karena Anomalica tidak menggunakan cookie dan tidak mengumpulkan data pribadi, tidak diperlukan banner persetujuan berdasarkan Peraturan Perlindungan Data Umum (General Data Protection Regulation/GDPR) atau Direktif ePrivasi (ePrivacy Directive). Pengunjung tidak dilacak, diidentifikasi, atau diprofilkan.

## Font

Jenis huruf dimuat dari Google Fonts, yang mungkin mencatat permintaan sesuai dengan kebijakan privasinya sendiri. Tidak ada layanan pihak ketiga lainnya yang dimuat di halaman ini.

## Graf pengetahuan

Graf pengetahuan yang dapat diunduh berisi informasi yang diekstrak dari dokumen sumber yang tersedia secara publik. Graf ini tidak mengandung data pribadi tentang pengunjung situs.

## Hak subjek data

Berdasarkan Peraturan Perlindungan Data Umum (General Data Protection Regulation/GDPR), individu memiliki hak untuk mengakses, memperbaiki, dan menghapus data pribadi mereka. Karena Anomalica tidak mengumpulkan data pribadi, tidak ada data yang dapat diakses, diperbaiki, atau dihapus.

Jika Anda yakin Anomalica menyimpan data pribadi tentang Anda, atau jika Anda memiliki pertanyaan tentang kebijakan ini, hubungi privacy@anomalica.is.

## Perubahan kebijakan ini

Kebijakan ini dapat diperbarui. Perubahan berlaku setelah dipublikasikan di halaman ini. Riwayat perubahan lengkap tersedia di repositori konten.
