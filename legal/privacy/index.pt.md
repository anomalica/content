O Anomalica foi concebido para respeitar a privacidade dos visitantes. Esta página explica que dados são recolhidos, como são utilizados e que direitos os visitantes têm.

## Análise

O Anomalica utiliza o GoatCounter, uma ferramenta de análise web de código aberto que respeita a privacidade. O GoatCounter não utiliza cookies, não recolhe dados pessoais e não efetua impressões digitais de dispositivos.

São recolhidos os seguintes dados agregados:

- Páginas visitadas
- Website de referência (de onde veio)
- Localização ao nível do país (derivada do endereço IP, que não é armazenado)
- Tipo de navegador e tamanho do ecrã

Estes dados são utilizados para compreender como o site é utilizado e para priorizar conteúdo. Não podem ser utilizados para identificar visitantes individuais.

O GoatCounter é auto-alojado em infraestrutura da União Europeia. Os dados de análise não são partilhados com terceiros.

## Cookies

O Anomalica não define cookies. As preferências de modo escuro e unidades do visitante são armazenadas no armazenamento local do navegador. Estes dados nunca saem do dispositivo do visitante e não são acessíveis ao Anomalica.

## Consentimento

Como o Anomalica não utiliza cookies e não recolhe dados pessoais, não é necessário um banner de consentimento ao abrigo do Regulamento Geral sobre a Proteção de Dados (RGPD) ou da Diretiva da Privacidade Eletrónica. Os visitantes não são rastreados, identificados ou perfilados.

## Tipos de letra

Os tipos de letra são carregados a partir do Google Fonts, que pode registar pedidos de acordo com a sua própria política de privacidade. Nenhum outro serviço de terceiros é carregado na página.

## Grafo de conhecimento

O grafo de conhecimento transferível contém informação extraída de documentos-fonte disponíveis publicamente. Não contém dados pessoais sobre os visitantes do site.

## Direitos dos titulares dos dados

Ao abrigo do Regulamento Geral sobre a Proteção de Dados (RGPD), os indivíduos têm o direito de aceder, retificar e apagar os seus dados pessoais. Como o Anomalica não recolhe dados pessoais, não existem dados para aceder, retificar ou apagar.

Se acredita que o Anomalica detém dados pessoais sobre si, ou se tem perguntas sobre esta política, contacte privacy@anomalica.is.

## Alterações a esta política

Esta política pode ser atualizada. As alterações entram em vigor quando publicadas nesta página. O histórico completo de alterações está disponível no repositório de conteúdo.
