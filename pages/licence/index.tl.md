## Nilalaman: Creative Commons Zero 1.0 Universal (CC0 1.0)

Ang lahat ng ensiklopedyang nilalaman ay inilabas sa public domain sa ilalim ng [Creative Commons Zero 1.0 Universal (CC0 1.0)](https://creativecommons.org/publicdomain/zero/1.0/).

Saklaw nito ang:

- Mga pinagsama-samang artikulo sa lahat ng wika
- Mga claim at kanilang mga pagkilala
- Mga marka ng ebidensya at algorithmic na pagtatasa
- Ang nada-download na SQLite knowledge graph
- Mga salin na ginawa ng assembly pipeline

Sinuman ay maaaring gumamit, kumopya, magbago, at muling mamahagi ng nilalamang ito para sa anumang layunin nang hindi humihingi ng pahintulot o nagbibigay ng pagkilala.

## Code: MIT Licence

Ang lahat ng source code sa mga repository ng Anomalica ay inilabas sa ilalim ng [MIT Licence](https://opensource.org/licenses/MIT). Saklaw nito ang:

- Ang static site (anomalica-site)
- Ang ingester, digester, at assembler pipeline
- Mga pantulong na kasangkapan at script

## Materyal na pinagmulan

Ang mga orihinal na dokumento kung saan kinukuha ang mga claim ay nagpapanatili ng kanilang sariling katayuan sa copyright. Ang mga ulat ng pamahalaan, mga transcript ng pagdinig, mga artikulo sa balita, mga libro, at iba pang nailathala na materyal ay saklaw ng mga batas ng kani-kanilang hurisdiksyon.

Ang mga bukas na lisensya ng Anomalica ay nalalapat sa nakuha at pinagsama-samang output, hindi sa mismong materyal na pinagmulan. Ang knowledge graph ay naglalaman ng mga structured na claim na may provenance metadata ngunit hindi inilalathala nang buo ang mga dokumentong pinagmulan.

## Mga component ng third-party

Gumagamit ang site ng mga open-source na software component sa ilalim ng kani-kanilang lisensya:

- Hugo (Apache 2.0)
- Tailwind CSS (MIT)
- Alpine.js (MIT)
- GoatCounter (European Union Public Licence)
- Noto Sans typeface (SIL Open Font Licence)
- Outfit typeface (SIL Open Font Licence)

## Mga tanong

Para sa mga tanong tungkol sa lisensya, makipag-ugnayan sa legal@anomalica.is.
